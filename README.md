# Lanterne

Une petite voyageuse traverse une grotte sans fin avec sa lanterne. La lumière baisse : ramasse les fioles d'huile, évite la roche et les chauves-souris.

Maintiens espace, clic ou ↑ pour monter, relâche pour descendre. La flamme baisse sans arrêt : chaque fiole d'huile la ravive. Si elle s'éteint, la partie est finie. Les fioles brillent un peu dans le noir.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Lanterne → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
